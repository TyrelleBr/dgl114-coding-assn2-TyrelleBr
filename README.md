# Shiny Hunt Tracker

    - [Introduction](#introduction)
      -For Coding assignment 2 I kept it simple only adding 1 extra activity for now. In Shiny Hunt Tracker there is now a few rows that were made using xml, an adapter, and viewBinding (The feature to add new hunts will be worked  on for coding assignment 3). The info from these hunts will dynamically populate the previously created encounter counter screen (made for coding assignment 1).
    - [Features](#features) 
      -View a premade list of active shiny hunts 
      -Display pokemon names, pokemon game names, and the encounters number in the row cards and encounter counter screen.
      -Able to press the start button on a hunt to bring user to the encounter counter screen with dynamically updated information (dynamic pokemon image sprites coming next assignment)
    - [Technologies Used](#technologies-used)
      - Kotlin: A modern programming language used to build 
      - Android Studio
      - XML layouts
      - jetpack compose
      - recycler view
      - view binding
      - fragments
      - Android Intents
